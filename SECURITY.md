# Security

Use [GitHub Security](https://github.com/Viujnik/FuRy/security) to report a suspected vulnerability privately. If private reporting is unavailable, contact the maintainer for a private channel. Include the affected version, impact and a description using public data.

Use trusted Python schema sources and generated registry artifacts. Bound input before receiving it across a transport or binding, and restrict the size of SQL result sets. Pass query values as parameters. Verify the server hostname and CA for remote PostgreSQL using `sslmode=verify-full`. Deploy the wheel, generated TypeScript and WASM from coordinated revisions.
